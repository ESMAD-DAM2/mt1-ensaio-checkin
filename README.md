# Ensaio MT1 - Check-in (Aula 10)

Isto **não conta para nota**. Serve para treinar o fluxo do Mini-teste 1: aceitar o assignment no GitHub Classroom, clonar, desenvolver e fazer push.

## O que fazer

1. Aceite o assignment pelo link que o docente partilhar.
2. Clone o repositório criado para a sua conta (botão **Code** no GitHub).
3. Abra a pasta no VS Code.
4. No terminal: `flutter pub get` e depois `flutter run -d chrome`.
5. Implemente a app do enunciado PDF (Check-in) em `lib/main.dart`.
6. Quando terminar: `git add .`, `git commit -m "ensaio check-in"`, `git push`.

## Regras (iguais às do teste)

- Textos, cores e estrutura fixos: sem personalização.
- Sem pacotes extra.
- Corre no Chrome.
- Coloque o seu **nome e número** num comentário no topo de `lib/main.dart`.

## Depois do push

Feche o PC quando o docente pedir. A segunda parte do ensaio é em papel, sobre o código que submeteu.
